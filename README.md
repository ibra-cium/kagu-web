# kagu-web

BNLang v2 Web IDE — An in-browser IDE, C transpiler, and tree-walking interpreter for BNLang (Bangalish programming language).

## 🚀 Features
- **In-Browser Execution**: Runs pure JavaScript Emscripten builds with 0 external backend dependencies.
- **Transpiler & Inspector**: View Generated C Code, Abstract Syntax Tree (AST), and Token Stream in real-time.
- **Interactive Stdin**: Full support for `nao()` input calls.
- **Syntax Cheatsheet**: Built-in reference for BNLang v2 syntax (Variables, Arrays, Pointers, Compound Ops, Bangalish Logic words).
- **Mobile Friendly**: Responsive design with segmented layout for mobile devices.

## 🛠️ Usage
Open `index.html` in any browser or enable GitHub Pages under repository Settings -> Pages.
